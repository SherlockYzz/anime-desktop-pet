📖 玩法指南 (HOW TO PLAY)

🎯 游戏目标

在 10×20 冰原重力井中操作方块下落，填满水平整行进行爆破消除，防止堆积触顶！

📜 核心机制与翻转特性
  • 大小形状不变：方块具备坚实刚体结构，几何大小恒定。
  • 90° 旋转：按 W / ↑ 顺时针旋转方位，带踢墙与踢地保护。
  • 左右水平镜像：按 Q / F 键进行左右方位对调翻转。
  • 上下垂直翻转：按 E / V 键进行上下翻转，可倒转卡进复杂缝隙。
  • 暂存 Hold：按 C / Shift 键可将当前块存入备用仓换牌（每回合限一次）。
  • 虚影预览 (Ghost)：井底实时投射半透明虚影，提前知晓精准落点。
🎮 双端操作键位指南
  • 电脑端键盘：
    • 平移：A / ← 左移，D / → 右移
    • 下落：S / ↓ 慢降，Space 瞬降锁定
    • 姿态：W / ↑ 旋转，Q / F 左右翻转，E / V 上下翻转
    • 暂存：C / Shift
  • 手机/平板触控：
    直接点击底部虚拟手柄对应的【左移】【右移】【慢降】【瞬降】【旋转】【左右翻转】【上下翻转】【暂存】即可。
